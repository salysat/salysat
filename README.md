## 👋 About me

I'm **Mohamed Nabil Mohamed**, a **Software Architect, .NET Team Lead, and Full-Stack Developer** with **10+ years of experience** building business software.

My work focuses on turning complex requirements into maintainable applications, including **legal practice management**, **point-of-sale systems**, **customer service platforms**, and **enterprise dashboards**. I enjoy solving problems across the entire software lifecycle: requirements, database design, backend services, user experience, and deployment.

- 🏗️ **Focused on:** Software architecture, enterprise applications, and system integration.

- 🧠 **Exploring:** Tokenization, attention, Transformers, training loops, and model optimization.
- 🤝 **Open to:** .NET, SaaS, open-source, and practical AI collaborations.
- 💬 **Ask me about:** C#, ASP.NET Core / MVC, SQL Server, REST APIs, architecture, and full-stack development.
